5. **멈추는 선**: 묶음 0 → 0.5 → 0.7 → 1 → 1.5 → 2 → 2.5 (약 90~110시간),
   그다음 묶음 5 + H6·G6 (약 60~80시간). **여기서 멈추고 재판단한다.**
